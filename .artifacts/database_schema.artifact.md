# Esquema de Base de Datos para Supabase (DashCore)

Este documento contiene el script SQL necesario para configurar las tablas en el **SQL Editor** de tu proyecto de Supabase.

## 1. Tabla de Perfiles (`profiles`)
Esta tabla se vincula automáticamente con los usuarios creados a través de Supabase Auth.

```sql
-- Crear tabla de perfiles
CREATE TABLE public.profiles (
  id uuid REFERENCES auth.users ON DELETE CASCADE NOT NULL PRIMARY KEY,
  username text UNIQUE,
  avatar_url text,
  updated_at timestamp with time zone DEFAULT timezone('utc'::text, now())
);

-- Habilitar RLS
ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY;

-- Políticas de Seguridad
CREATE POLICY "Usuarios pueden ver su propio perfil" ON public.profiles
  FOR SELECT USING (auth.uid() = id);

CREATE POLICY "Usuarios pueden actualizar su propio perfil" ON public.profiles
  FOR UPDATE USING (auth.uid() = id);
```

## 2. Tabla de Configuración de Usuario (`user_settings`)
Guarda las preferencias estéticas del dashboard.

```sql
CREATE TABLE public.user_settings (
  user_id uuid REFERENCES public.profiles(id) ON DELETE CASCADE NOT NULL PRIMARY KEY,
  selected_style text NOT NULL DEFAULT 'sporty',
  accent_color text NOT NULL DEFAULT '#00E5FF',
  temp_unit text NOT NULL DEFAULT 'celsius',
  language text NOT NULL DEFAULT 'es',
  background_path text,
  model_path text DEFAULT 'assets/models/OPTIMA2012.GLB',
  updated_at timestamp with time zone DEFAULT timezone('utc'::text, now())
);

ALTER TABLE public.user_settings ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Usuarios pueden ver su propia configuración" ON public.user_settings
  FOR SELECT USING (auth.uid() = user_id);

CREATE POLICY "Usuarios pueden gestionar su propia configuración" ON public.user_settings
  FOR ALL USING (auth.uid() = user_id);
```

## 3. Tabla de Estilos Adquiridos (`user_styles`)
Controla qué dashboards ha "descargado" el usuario de la tienda.

```sql
CREATE TABLE public.user_styles (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id uuid REFERENCES public.profiles(id) ON DELETE CASCADE NOT NULL,
  style_id text NOT NULL,
  unlocked_at timestamp with time zone DEFAULT timezone('utc'::text, now()),
  UNIQUE(user_id, style_id)
);

ALTER TABLE public.user_styles ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Usuarios ven sus propios estilos" ON public.user_styles
  FOR SELECT USING (auth.uid() = user_id);

CREATE POLICY "Usuarios registran sus propios estilos" ON public.user_styles
  FOR INSERT WITH CHECK (auth.uid() = user_id);
```

## 4. Tabla de Actualizaciones (`app_versions`)
Tabla **pública** para el control de versiones.

```sql
CREATE TABLE public.app_versions (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  version_name text NOT NULL,
  version_code bigint NOT NULL,
  min_version_code bigint NOT NULL,
  title text NOT NULL,
  changelog text,
  download_url text NOT NULL,
  platform text NOT NULL DEFAULT 'android',
  is_active boolean DEFAULT true,
  is_mandatory boolean DEFAULT false,
  published_at timestamp with time zone DEFAULT timezone('utc'::text, now())
);

-- RLS para lectura pública
ALTER TABLE public.app_versions ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Lectura pública de versiones" ON public.app_versions
  FOR SELECT USING (true);
```

## 5. Triggers Automáticos
Para crear el perfil automáticamente cuando un usuario se registra.

```sql
-- Función para manejar nuevos usuarios
CREATE OR REPLACE FUNCTION public.handle_new_user()
RETURNS trigger AS $$
BEGIN
  INSERT INTO public.profiles (id, username)
  VALUES (new.id, new.raw_user_meta_data->>'username');

  INSERT INTO public.user_settings (user_id)
  VALUES (new.id);

  RETURN new;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

-- Trigger
CREATE TRIGGER on_auth_user_created
  AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE FUNCTION public.handle_new_user();
```
